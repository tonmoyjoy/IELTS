# Analytics

## Goal

Give users meaningful feedback about IELTS progress over time.

## Improvements

1. Add per-criterion trends.
   - Fluency
   - Lexical resource
   - Grammar
   - Estimated pronunciation

2. Add summary metrics.
   - Average band score
   - Best band score
   - Latest improvement
   - Number of practice attempts
   - Practice streak

3. Add transcript history tools.
   - Search transcripts
   - Filter by score range
   - Sort by date or score
   - View detailed attempt pages

4. Add personalized recommendations.
   - Identify weakest criterion
   - Suggest targeted practice prompts
   - Show improvement suggestions based on repeated mistakes

## Resume Value

Analytics turns the app into a learning product with retention, insight, and measurable progress.
