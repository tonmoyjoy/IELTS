# User Experience

## Goal

Make the speaking practice flow clearer, smoother, and more polished.

## Improvements

1. Improve recording controls.
   - Microphone permission states
   - Recording timer
   - Countdown before recording starts
   - Pause and resume if supported
   - Re-record option

2. Improve analysis states.
   - Uploading
   - Transcribing
   - Evaluating
   - Saving result
   - Complete

3. Improve error messages.
   - Missing API key
   - Microphone denied
   - Recording too short
   - Network failure
   - AI provider failure

4. Improve accessibility.
   - Keyboard-friendly controls
   - Visible focus states
   - Screen reader labels
   - Better contrast checks

5. Improve responsive design.
   - Mobile dashboard layout
   - Compact chart view
   - Better long transcript handling

## Resume Value

Strong UX shows product thinking, not just backend wiring.
